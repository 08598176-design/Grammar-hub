# inbox/ — the drop box

Andrew: put new files **here**, any way you like (GitHub web → Add file →
Upload files, straight to `main` is fine). Don't worry about naming or
folder structure — that's the assistant's job, and it avoids the filename
scrambling that happened with earlier bulk uploads.

Before uploading, run the 2-minute scrub checklist in
`collab/UPLOAD_GUIDE.md` (no student names, no student work, no internal
links, no keys). What's worth uploading, in priority order, is in the same
file.

Assistants: when files land here, check them against the scrub checklist
(anything that fails goes back to Andrew, not into the repo), file them into
a sensible folder, update any open question they answer, and leave this
folder empty apart from this README.
